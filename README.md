# 秋招 Tracker

一个面向秋招 / 校招求职者的 Windows 投递管理客户端。无需登录，数据保存在本机，用一套清晰的流程管理投递、面试与复盘。

## 核心功能

- **投递管理**：记录公司、岗位、志愿顺序、投递渠道、地点、截止日期和当前进度，支持任意数量的多志愿岗位。
- **流程看板**：通过拖动卡片推进招聘流程，按节点记录精确时间和完成状态，支持自定义、排序流程节点及撤销上一步流转。
- **待办与提醒**：根据进行中的笔试、面试等节点生成每日待办，支持提前提醒、开机后台运行和 Windows 桌面弹窗。
- **数据概览**：汇总投递数量、笔试率、面试率、Offer 率、投递趋势与即将截止的岗位。
- **面试复盘**：为每次笔试或面试关联独立的 Markdown 复盘，支持源码编辑、实时预览、代码高亮、导入及 Markdown / PDF 导出。
- **知识笔记**：使用 Markdown 整理技术知识与面试要点，支持常用格式工具、搜索、实时预览、导入及 Markdown / PDF 导出。
- **搜索筛选**：按关键词、公司、状态、地点和日期快速查找投递记录。
- **本地数据**：数据仅保存在本机，支持 JSON 完整备份与恢复、CSV 导出以及浅色 / 深色 / 系统主题。
